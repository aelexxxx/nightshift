# Experiments ledger

Every experiment gets an entry BEFORE it starts (see experiment-design
skill): hypothesis with a predicted number, one variable, sample/duration,
kill criteria. Closed experiments keep their entries — verdicts are the
company's accumulated wisdom.

## Template

```
## EXP-001: <short name>
- Goal it serves: <goal from goals.yaml>
- Hypothesis: <change X will move metric Y from A to B>
- Change (one variable):
- Sample/duration:
- Kill criteria:
- Status: planned | running (since DATE) | closed (DATE)
- Result: <numbers, verdict, lesson>
```
